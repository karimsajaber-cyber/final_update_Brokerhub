## Design Context

### Users
Customers use BrokersHub to submit buying requests and track broker responses. Brokers use it to review incoming requests, reply clearly, and move deals forward without confusion.

### Brand Personality
Helpful, trustworthy, modern. The interface should feel calm and clear, with enough polish to make messaging feel professional and safe.

### Aesthetic Direction
Preserve the current BrokersHub visual language: light surfaces, rounded cards, blue-violet accents, soft shadows, and simple responsive layouts. New chat screens should feel like part of the same product, not a different app.

### Design Principles
1. Keep customer-broker communication private and obvious.
2. Prefer clean, readable layouts over dense controls.
3. Make mobile usage first-class, not a reduced version.
4. Keep reporting visible but quiet so it does not distract from messaging.
5. Use simple interactions that are easy to maintain and extend later.
